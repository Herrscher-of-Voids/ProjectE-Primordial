# 更新日志

## 2.0.3 — NeoForge 1.21.1（2026-10-31）

修复定价器只有开启 JEI「Cheating → Show Hidden Ingredients」后才能找到的问题。

- 在现有 JEI 插件中单独注册定价器，默认配料列表不再依赖带权限过滤的创造目录收集结果。
- 创造物品栏的显示规则不变；获得或看到物品不会授予定价权限。服务端仍要求二级及以上管理员，或单人存档主人处于创造模式。
- 不覆盖玩家主动隐藏物品、整包隐藏标签或 JEI API 黑名单。不安装 JEI 时不增加额外前置。
- 保留 NeoForge `[21.1.119,21.2)` 和此前放宽的附属模组版本范围；配置、价格文件及存档格式不变。

验证：最低 NeoForge `21.1.119` 上生产构建和基础 GameTest `259/259` 通过；使用该最低版本编译的生产类，在 `21.1.264` 当前 43 模组开发服务端组合中 `300/300` 通过。已核对 JEI 附加注册 API、正式 JAR 内的回调及可选依赖隔离。未启动客户端或占用桌面，JEI 界面仍待玩家复测。

升级：删除旧版原初 JAR，换入 2.0.3 后重启游戏，让 JEI 重新收集物品。联机时客户端和服务端同时更新；若曾手动隐藏定价器，需要自行取消该隐藏设置。

## 2.0.2 — NeoForge 1.21.1（2026-10-31）

针对玩家反馈，降低原初的 NeoForge 加载器版本要求。

- NeoForge 要求从 `21.1.264+` 降为 `[21.1.119,21.2)`，支持 Minecraft 1.21.1 的更多加载器补丁版本。
- 最低版本与必需前置 ProjectE 1.1.0 自身的 `21.1.119` 要求一致；Curios 仍为必需前置。
- 保留 2.0.1 放宽后的可选附属模组版本范围。本次不改玩法、配置和存档格式。
- 其他已安装模组仍可能有自己的更高 NeoForge 要求；实际所需版本取所有模组要求的交集。

验证：在最低 NeoForge `21.1.119` 上完成生产构建和基础 GameTest，`259/259` 通过；`21.1.264` 上基础 `259/259`、当前 43 模组开发服务端组合 `300/300` 通过。客户端和长期性能未在本轮重新测试。

升级：删除旧版原初 JAR 后换入 2.0.2，客户端和服务端同时更新；已有存档可继续使用，升级前照常备份。无需为了原初单独升级到 `21.1.264`。
