# 更新日志

## 2.0.8 — NeoForge 1.21.1 转化接口修复测试包（2026-11-11）

- AE 和超越维度的原生虚拟库存改为按 EMC 计算，不再显示物理接口每 tick 传输上限；原生仓储交易支持整单请求，物理接口限速保留。
- 同账户同 AE 网络的多个转化接口不再重复计数；AE 初始合成取料失败按实际买价精确退款，保留未归还 CPU 材料，避免差价损耗及确认退款后的重复副本。
- AE 节点刷新延后至宿主 tick 的异常隔离范围；超越维度付款回调复核原付款人、当前实体、挂载身份及网络授权。
- 补齐超越维度原生终端的资源存在性查询，修复纯 EMC 资源被同步快照过滤、接入后目录为空的缺口。
- 包含此前 2.0.6、2.0.7 的修复。完整行为、验证记录和未覆盖范围见 `CHANGELOG-2.0.8.md`；本轮不宣称已复现所有玩家接入崩溃或连接失败搭法。

## 2.0.6 — NeoForge 1.21.1 修复包（2026-11-11）

针对玩家反馈，修复模组收纳物品无法卖入转化桌、更新版 JEI 缺少 EMC 按钮的问题，并恢复定价器的生存获取与使用。

- 转化桌不再一概拒绝模组物品库存；按空壳价值结算，内部物品先安全返还。精妙背包同时处理主库存和独立升级槽，清空真实 UUID 共享存储，避免内容重复领取；输出知识不保留库存身份。
- 对不能安全提取或恢复的库存继续拒绝交易，不通过直接删除容器数据解决兼容问题。背包无足够返还空间时保留原容器，不将内部物品丢到地上。
- JEI 数量渲染同时匹配旧包名和新版 `overlay.ingredients` 包名，按钮同时挂接旧 `drawScreen` 与新版 `drawForeground` 入口，并避免重复绘制。
- 恢复搜索栏旁的 `E` 按钮：切换 EMC 可兑换数量显示；开启时 Shift＋左键兑换一组已学习物品，沿用服务端校验和原有偏好保存。
- 定价器新增生存合成：4 钻石、2 纸、2 暗物质和 1 时钟。获得暗物质后解锁配方书，也可在 JEI 查看。
- 定价器进入普通创造目录与搜索目录，取消管理员专属显示和额外 JEI 收录补丁。普通玩家主手或副手持有定价器即可打开并修改公共 EMC 价表。
- 保留真实工具、菜单身份、目标、修订与服务端线程检查；失去手持工具后菜单失效。`set_value`、`reload_values` 等管理员指令仍要求二级权限。
- 保留最低 NeoForge `[21.1.119,21.2)`、既有依赖范围和存档格式。

验证：最低 NeoForge `21.1.119`＋JEI `19.27.0.340` 的生产构建及 GameTest `267/267` 通过。同一最低版本编译的生产类在 NeoForge `21.1.265`、本地附属模组开发服务端环境中 `308/308` 通过，包含 JEI `19.69.0.457`、精妙背包 `3.26.14.2222` 和精妙核心 `1.5.17.2426`。实际基础背包默认有正 EMC 价格的断言通过；真实主库存、升级槽、共享 UUID 别名及学习空壳去身份检查通过。新增回归还覆盖两种售卖入口、部分提取与提交异常、重入、空间不足、128 件内容拆堆、非 OP 生存开屏与 C2S 保存，以及两版 JEI 实际渲染字节码挂接。未启动客户端，真实 GUI 与第三方所有库存实现不能由后台测试替代。本包为修复复测包，尚未新建正式 GitHub Release。

升级：备份存档，删除旧原初 JAR，换入修复包后完全重启游戏；联机时客户端和服务端同时更新。容器本身仍须具有正 EMC 价格，内部物品和升级不计入空壳卖价。定价器修改的是服务器公共价表，不是玩家私有价格。

## 2.0.5 — NeoForge 1.21.1（2026-11-08）

修复单人模式查看/转化附魔物品后，暂停或退出保存时报 `Saving entity NBT`、`is not valid in current registry set` 的崩溃。玩家报告中的触发物品是亡灵杀手 IV 附魔书。

- 知识查询和安全组件保留按逻辑侧选择注册表：客户端使用客户端世界，服务端使用服务端，避免整合服两端混用。
- 组件校验使用独立的编码缓存上下文，防止一次无效引用的试编码污染正常物品保存；同样覆盖名称/描述中嵌套物品的编码。
- 保留有效物品的附魔、名称和附魔提示开关，不删除玩家物品，不改变网络协议、配置、存档格式或依赖范围。

验证：旧代码的附魔书及嵌套物品保存回归均复现相同错误；修复后最低 NeoForge `21.1.119` 生产构建和基础 GameTest `263/263` 通过。该生产代码在报告所用 `21.1.265`、本地附属模组开发服务端环境（加载 51 个 mod ID，含 Minecraft 和 NeoForge）中 GameTest `304/304` 通过。包含原生 ProjectE 持久化接口、保存后恢复、附魔及源物品不变检查；后者并非玩家报告中的全部模组组合。当前客户端未启动，整合服实际界面仍需玩家复测。

升级：备份存档，删除旧原初 JAR，换入 2.0.5 后**完全退出并重启游戏进程**；联机时客户端和服务端同时更新。无需删除附魔书。崩溃前尚未成功保存的进度无法由此补丁恢复。
