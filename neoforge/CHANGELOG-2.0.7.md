# 原初 2.0.7 修复测试包 — NeoForge 1.21.1

在 2.0.6 的容器售卖、JEI 按钮和生存定价器修复基础上，补齐容器成交异常时的充能回滚。

- 容器交易失败时同时恢复转化桌输入槽、克莱因之星充能、玩家背包、知识和账户余额，避免退回原物品后仍留下新增 EMC。
- 无法安全撤销的第三方 EMC 储能物品放在转化桌充能槽时，会在消耗容器前拒绝该笔售卖；先取下该储能物品即可。原生克莱因之星继续按 ProjectE 规则充能。
- 未覆盖此前交付的 2.0.6 JAR；本包使用独立版本和校验值。

定价器修改的是服务器公共价格。支持的收纳物品仍须有正 EMC 价格，并有足够背包空间返还内部物品。未启动客户端，游戏界面仍需实测。

验证：使用 NeoForge 21.1.119 构建，旧 JEI 环境 270/270 项 GameTest 通过；相同生产类在 NeoForge 21.1.265 与本地附属整包环境 311/311 项通过，包含真实精妙背包和真实克莱因之星回归。两轮均未启动客户端。源码同步不等于已创建正式 GitHub Release。
