## 已知缺口与待核对项

1. **客户端回归**：先确认定价器可在创造栏和 JEI 默认列表中查找，再验转化桌物品/流体/气体目录、搜索分页、JEI 转移/购买/退款、机器配置器和资源端口。2.0.4 改动涉及客户端创造目录缓存，本次只有离线 hook 检查，没启动客户端。
2. **1.20.1 分页实现存在源代码差异**：Forge 目录标记页面容量 16、步长 12，但当前实现单页切片最多返回 12；NeoForge 返回最多 16 并步进 12。需按 1.20.1 实际游戏表现与用户预期核定，不能只凭常量说两版一致。见 Forge [`TransmutationMediaCatalog.java`](../src/main/java/com/primordial/service/TransmutationMediaCatalog.java#L85) 与 NeoForge [`NeoForgeTransmutationMediaCatalog.java`](src/main/java/com/primordial/neoforge/transmutation/NeoForgeTransmutationMediaCatalog.java#L28)。
3. **Beyond Dimensions**：测试包未包含 KubeJS 自定义 `ExtractRule`；针对这些规则的事务行为未移植。
4. **依赖范围**：2.0.1 放宽 FTB Quests、AE2、RS 2、Beyond Dimensions 元数据范围；自动测试只覆盖记录中的具体 API 基线版本，不能推导范围内每一版都已验证。
5. **明确的效果限制**：Fortune 等级超过 26000 时保留等级、拒绝该效果且不收费；这是保护限制，不是“完整兼容任意等级”。AE2 休眠/调度状态缺少当前使用的公开查询 API。
6. **用户明确暂缓**：Astral Sorcery、Oritech 的实际资源适配和 Oritech EMC/碰撞能匹配不计作已实现功能，也不在本轮缺陷修复范围。

本次只读盘点没有启动客户端，也没有发现可以仅凭静态证据确认的新运行时故障。上面“未复测/待核对”不等同于已证明失败；具体异常须由复测或可复现报告确认。
